# ClaiDevSkill

让 AI 开发时自己写文档、做记录的一套方法。

多人协作最乱的就是文档：散落在各处，谁都不知道上次做到哪了。这个方法是让 AI 在动手之前，先自己判断这事归哪个模块，然后把开发中遇到的坑、做什么不做什么、怎么做，全都记在这个模块下面。人为分类是做不清楚的，做不清楚就会打架，所以分类这件事交给干活的 AI 自己来做。

好处很实在：换个电脑、换个人、换个 AI，读一下文档就能接着干，不用问上次做到哪。记录的格式永远一个样，AI 有样学样，工作风格始终统一，杂念少了，幻觉和不听话也就少了。注意它治理不了幻觉，只是让干扰变少。

用法就一步：把这个仓下载到你的项目根目录，然后直接跟 AI 说需求，随便说就行，剩下的它自己会按流程走。

我建议每个项目都用这个方法。
